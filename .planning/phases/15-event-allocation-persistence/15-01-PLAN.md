    Money allocations: For each person, create a PersonMoneyAllocation with:
    - amount = Math.floor((totalBudget / personIds.length) * 100) / 100 (equal share, rounded down to cents)
    - If totalBudget is 0: amount = 0 (still create the allocation entry for diffAllocations)
