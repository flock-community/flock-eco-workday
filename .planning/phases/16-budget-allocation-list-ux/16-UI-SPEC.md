## Spacing Scale

MUI uses an 8px base spacing unit (`theme.spacing(1) = 8px`). All `sx` props below map to this scale.

| Token | MUI Value | CSS Value | Usage |
|-------|-----------|-----------|-------|
| xs | `spacing(0.5)` | 4px | Icon gaps (`gap: 0.5`), tight inline padding |
| sm | `spacing(1)` | 8px | Chip row gaps, list item inner spacing |
| md | `spacing(2)` | 16px | Default element spacing, card padding inner |
| lg | `spacing(3)` | 24px | Card/Paper outer padding (`p: 3`) |
| xl | `spacing(4)` | 32px | Section vertical separation |
| 2xl | `spacing(6)` | 48px | Major section breaks |
| 3xl | `spacing(8)` | 64px | Page-level spacing |

Exceptions:
- Filter chip row uses `spacing={1}` (`Stack spacing={1}`) — matches existing BudgetAllocationFeature implementation (source: BudgetAllocationFeature.tsx line 196)
- AccordionSummary hover area: inherits MUI Accordion default (no override required)
- Touch targets for clickable Link rows: minimum 44px height enforced by MUI ListItem defaults

| Role | MUI Variant | Approx Size | Weight | Line Height |
|------|-------------|-------------|--------|-------------|
| Body | `body2` | 14px | 400 (regular) | 1.43 |
| Label | `subtitle2` | 14px | 500 (medium) | 1.57 |
| Heading | `subtitle1` | 16px | 500 (medium) | 1.75 |
| Display | `h6` | 20px | 500 (medium) | 1.6 |

Two weights only: **400 (regular)** and **500 (medium)**. `fontWeight="medium"` and `fontWeight="bold"` map to these in MUI system. (Source: confirmed across BudgetCard.tsx, EventAllocationListItem.tsx, BudgetAllocationList.tsx.)

## Component Inventory

The single implementation change for Phase 16 is the event link href fix in `EventAllocationListItem`. All other components are already correct.

### EventAllocationListItem (PRIMARY CHANGE)

File: `workday-application/src/main/react/features/budget/EventAllocationListItem.tsx`

**Current state (line 148):**
```
<Link href="/event" underline="hover" ...>
```

**Required state after fix:**
```
<Link href={`/event?code=${eventCode}`} underline="hover" ...>
```

Interaction contract:
- Admin role: renders MUI `Link` component with `href="/event?code={eventCode}"`, `underline="hover"`, `OpenInNew` icon (16px, `sx={{fontSize: 16}}`), `display: "inline-flex"`, `alignItems: "center"`, `gap: 0.5`
- Employee role: renders plain text (no Link, no icon) — already correctly implemented via `isAdmin` prop
- The link opens in the same tab (no `target="_blank"`) — EventFeature will consume the `?code=` param in a future phase (#458)

- Filter chips: All / Hack Hours / Study Hours / Study Money with filled/outlined toggle (source: lines 196-222)
- Event filter banner with clear chip (source: lines 175-192)

### BudgetAllocationList (NO CHANGE NEEDED)

Already correctly:

- Passes `eventNameMap[item.data.eventCode] || item.data.eventCode` as fallback (source: line 126)

Already implemented. Contract for reference:

| State | Visual |

| Filter active | Matching type chip: `variant="filled"` `color="primary"`, others: `variant="outlined"` `color="default"` |
