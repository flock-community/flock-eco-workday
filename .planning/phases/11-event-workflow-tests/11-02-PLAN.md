**Part A: Add new helpers to `tests/steps/eventSteps.ts`**

Add these exported helper functions to the existing eventSteps.ts file:

1. `When_I_customize_participant_hours(page: Page, personName: string, periodType: 'Study Time' | 'Hack Time', dayIndex: number, hours: string)`:
   - Find the participant row containing the personName text
   - Within that row, find the section labeled with periodType (e.g., "Hack Time")
   - The PeriodInput renders a series of number inputs for each day. Locate the input at dayIndex position within that section's PeriodInput.
   - Clear the input and fill with the new hours value
   - Implementation approach: locate the participant Box by personName, then within it find the section with the periodType subtitle2 text, then find the `input[type="number"]` elements and target the one at dayIndex

2. `When_I_remove_participant_from_event(page: Page, personName: string)`:
   - In the EventForm, the PersonSelectorField renders selected participants as MUI Autocomplete chips
   - Each chip has a cancel/delete icon (SVG with data-testid="CancelIcon" or an icon button)
   - Find the chip containing personName text within the Person autocomplete area
   - Click its delete icon to remove the participant
   - Implementation: `page.getByLabel('Person').locator('..').locator('.MuiChip-root').filter({ hasText: personName }).locator('[data-testid="CancelIcon"]').click()`
   - Wait briefly for the form to update: `await page.waitForTimeout(300)`

3. `When_I_add_second_participant(page: Page, personName: string)`:
   - Same as When_I_add_participant but for adding to an already-populated PersonSelector
   - Click the Person autocomplete input: `page.getByLabel('Person').click()`
   - Type to filter: `page.getByLabel('Person').fill(personName)` -- but in multiple mode, fill may clear existing chips. Instead: `page.getByLabel('Person').pressSequentially(personName, { delay: 50 })`
   - Wait for dropdown: `await page.waitForTimeout(500)`
   - Click option: `page.getByRole('option', { name: new RegExp(personName, 'i') }).click()`
