**Helper functions to implement:**

1. `Given_I_am_on_events_page(page: Page, adminUser: string)`:
   - Call `Given_I_am_logged_in_as_user(page, adminUser)`
   - Navigate to `/event`
   - Wait for the EventList to render: `await expect(page.getByRole('heading', { name: 'Events' })).toBeVisible()`

2. `When_I_click_add_event(page: Page)`:
   - Click the "Add" button: `page.getByRole('button', { name: 'Add' }).click()`
   - Wait for EventDialog to open: `await expect(page.locator('form#event-form')).toBeVisible()`

3. `When_I_fill_event_form(page: Page, options: { description: string, budget: string, eventType: string, from: string, to: string, hoursPerDay?: string })`:
   - Fill Description: `page.getByLabel('Description').fill(options.description)`
   - Fill Budget: `page.getByLabel('Budget').fill(options.budget)` (clear first)
   - Select Event type: locate the FormControl with label "Event type" via `page.locator('.MuiFormControl-root').filter({ hasText: 'Event type' }).first()`, then click its combobox `.getByRole('combobox').click()`, then pick option `page.getByRole('option', { name: options.eventType }).click()`
   - Set From date: use `page.getByLabel('From')` -- fill with ISO date string (the DatePickerField uses an HTML date input)
   - Set To date: use `page.getByLabel('To')` -- fill with ISO date string
   - Note: Default Time Allocation Type is auto-set by event type selection (FLOCK_HACK_DAY -> Hack, CONFERENCE -> Study). Do NOT manually set it.
   - Note: PeriodInput defaults to 8h/day which is fine for test purposes.

4. `When_I_add_participant(page: Page, personName: string)`:
   - The PersonSelectorField is an MUI Autocomplete with label "Person". It is `multiple` mode.
   - Click the autocomplete input: `page.getByLabel('Person').click()`
   - Type the person name to filter: `page.getByLabel('Person').fill(personName)`
   - Wait briefly for dropdown: `page.waitForTimeout(500)`
   - Click the matching option: `page.getByRole('option', { name: new RegExp(personName, 'i') }).click()`

5. `When_I_submit_event_form(page: Page)`:
   - Click the submit button in DialogFooter. The DialogFooter renders a submit button with type="submit" for form `event-form`. Locate: `page.locator('button[type="submit"][form="event-form"]').click()`
   - If that selector is too specific, fall back to: `page.getByRole('button', { name: /save|submit/i }).click()` inside the dialog footer.
   - Wait for dialog to close and network to settle: `await page.waitForLoadState('networkidle')`

6. `When_I_open_event_by_description(page: Page, description: string)`:
   - Find the event card in EventList: `page.locator('.MuiCard-root').filter({ hasText: description }).first()`
   - Click on it: `.click()`
   - Wait for EventDialog to open with the form: `await expect(page.locator('form#event-form')).toBeVisible()`
   - Wait for budget data to load: `await page.waitForLoadState('networkidle')`

7. `When_I_expand_budget_accordion(page: Page)`:
   - The main budget Accordion has AccordionSummary containing EventBudgetSummaryBanner. The banner contains text like "Budget Allocations" or participant count info.
   - Click the accordion summary that contains budget info. Use: `page.locator('.MuiAccordion-root').first().locator('.MuiAccordionSummary-root').first().click()` -- but this is fragile. Better: look for the accordion that contains budget-related text.
   - More reliable: `page.getByText('Budget Allocations').first().click()` -- since the EventBudgetSummaryBanner renders this text.
   - Wait for accordion to expand: `await expect(page.getByText('Time Budget Allocations').or(page.getByText('Money Budget Allocations')).or(page.getByText('No budget allocations'))).toBeVisible({ timeout: 5000 })`

8. `When_I_expand_time_accordion(page: Page)`:
   - Click: `page.getByText('Time Budget Allocations').click()`
   - Wait for content: `await expect(page.getByText('Time Allocation')).toBeVisible()`

9. `When_I_click_show_all_participants(page: Page)`:
   - Click the "Show all participants" button: `page.getByRole('button', { name: /Show all participants/i }).click()`
   - Wait for participant rows to appear

10. `When_I_save_event(page: Page)`:
    - Same as `When_I_submit_event_form` -- clicks the submit button for `event-form`
    - `page.locator('button[type="submit"][form="event-form"]').click()`
    - Wait for dialog close: `await page.waitForLoadState('networkidle')`
    - If the EventDialog stays open due to close-warning (dirty budget), handle it: check if "You have unsaved budget changes" appears, and if so click Confirm.

11. `Then_event_list_contains(page: Page, description: string)`:
    - Assert the event card exists: `await expect(page.locator('.MuiCard-root').filter({ hasText: description }).first()).toBeVisible()`

12. `Then_budget_tab_shows_event_allocation(page: Page, allocationTypeText: string, hoursOrAmount: string)`:
    - On the budget tab, event allocations appear in EventAllocationListItem cards.
    - For time: look for text like "Hack Time: 8h" or "Study Time: 8h" within the allocation list
    - `const paper = page.locator('.MuiPaper-root').filter({ hasText: 'Budget Allocations' })`
    - `await expect(paper.getByText(new RegExp(allocationTypeText + '.*' + hoursOrAmount))).toBeVisible()`
