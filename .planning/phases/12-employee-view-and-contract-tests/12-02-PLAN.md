2. Navigate to contracts: `await page.goto('/contracts');`
3. Wait for page: `await page.waitForLoadState('networkidle');`
4. Select Pino in the PersonSelector. PersonLayout's PersonSelector has label "Select person" and is a full MUI Autocomplete (not the embedded Select used in BudgetAllocationFeature). Use this pattern:
   ```typescript
   // PersonLayout uses PersonSelector with label "Select person"
   await page.getByLabel('Select person').click();
   await page.getByRole('option', { name: /Pino/i }).click();
   await page.waitForLoadState('networkidle');
   ```
   NOTE: If PersonSelector in PersonLayout is an Autocomplete (not Select), the click-to-open pattern may differ. If `getByLabel('Select person').click()` doesn't open a dropdown, try:
   ```typescript
   const personField = page.getByLabel('Select person');
   await personField.click();
   await personField.fill('Pino');
   await page.getByRole('option', { name: /Pino/i }).click();
   ```
5. Wait for contract list to load: `await page.waitForLoadState('networkidle');`
6. Click on the INTERNAL contract card to open ContractDialog:
   ```typescript
   // ContractList renders cards with "INTERNAL" text for internal contracts
   ```
