## Edge cases in the swap

| Option | Description | Selected |
|--------|-------------|----------|
| Delete all time allocations for that person, recreate fresh | Wipe all time allocs for this person on this event, create exactly one of the new type. | ✓ |
| Delete only the mismatched one, keep the matching one | More targeted but more logic; correct one may still have stale hours. | |

**User's choice:** Delete all time allocs for this person+event, create one fresh.
**Notes:** User clarified that a person MAY have both HackTimeBudgetAllocation and StudyTimeBudgetAllocation for the same event — this is an allowed state. The delete-all-then-recreate approach handles this correctly. User also confirmed both unit tests and Playwright e2e tests should cover this edge case.
