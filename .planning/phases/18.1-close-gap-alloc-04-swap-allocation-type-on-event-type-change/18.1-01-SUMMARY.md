## Structural Change

**Before (lines 243–304):** Single-match via `firstOrNull` on `personAllocations` followed by a `when` branch that called `.update()` on the matched service. If the existing allocation was the wrong type (e.g., `HackTimeBudgetAllocation` but event is now `STUDY_TIME`), it would be updated in-place with `copy(...)`, leaving the wrong concrete type in the database.

**After (lines 243–268 in modified file):** Filter ALL time-typed allocations (`HackTimeBudgetAllocation` or `StudyTimeBudgetAllocation`) from `personAllocations` into `existingTimeAllocations`, delete each via `budgetAllocationService.deleteById(it.id)`, then unconditionally create exactly one allocation of the correct type (`isHack` → `HackTimeBudgetAllocation`, else `StudyTimeBudgetAllocation`).
