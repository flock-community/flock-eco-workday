# Phase 18.1 Plan 03: EVNT-07 Playwright Test for ALLOC-04 Type-Swap Summary

Adds Playwright e2e test EVNT-07 and step helper `When_I_change_event_type_to` to cover the ALLOC-04 behavior: changing event type via the UI swaps all participant allocations from Hack Time to Study Time.

## New Step Helper

**Function:** `When_I_change_event_type_to(page: Page, eventTypeOption: string): Promise<void>`

**Inserted in:** `tests/steps/eventSteps.ts`, immediately after `When_I_fill_event_form` (before `When_I_add_participant`)

**Implementation:** Copies the MUI Select pattern from `When_I_fill_event_form` lines 61-67:
```typescript
const eventTypeControl = page
  .locator('.MuiFormControl-root')
  .filter({ hasText: 'Event type' })
  .first();
await eventTypeControl.getByRole('combobox').click();
await page.getByRole('option', { name: eventTypeOption }).click();
```

No Escape press — MUI Select auto-closes on selection.
