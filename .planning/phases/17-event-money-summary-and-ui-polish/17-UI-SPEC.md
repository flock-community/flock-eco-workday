## Spacing Scale

MUI uses an 8px base spacing unit (`theme.spacing(1) = 8px`). All `sx` props below map to this scale.

| Token | MUI Value | CSS Value | Usage |
|-------|-----------|-----------|-------|
| xs | `spacing(0.5)` | 4px | Icon gaps, tight inline padding |
| sm | `spacing(1)` | 8px | Chip row gaps, list item inner spacing |
| md | `spacing(2)` | 16px | Default element spacing, card padding inner |
| lg | `spacing(3)` | 24px | Card/Paper outer padding |
| xl | `spacing(4)` | 32px | Section vertical separation |
| 2xl | `spacing(6)` | 48px | Major section breaks |
| 3xl | `spacing(8)` | 64px | Page-level spacing |

Exceptions:
- Collapsed banner summary row: `gap: 1.5` (12px) between dot indicator, text, and chip row — matches existing `EventBudgetSummaryBanner` line 81 (source: EventBudgetSummaryBanner.tsx)
- Chip row within banner: `gap: 1` (8px) — matches existing implementation

| Role | MUI Variant | Approx Size | Weight | Line Height |
|------|-------------|-------------|--------|-------------|
| Body | `body2` | 14px | 400 (regular) | 1.43 |

## Interaction States

### EventBudgetSummaryBanner — Collapsed Mode (SUMM-01)

The collapsed banner is rendered inside `EventDialog`'s `AccordionSummary`. It is read-only (no interactive elements within the summary text itself).

| State | Visual |
|-------|--------|
| No budget set | `Typography body2`: "N participants × Xh/day {type} - no budget allocations for this event type" (when no money budget) |
| Budget set, partially allocated | `Typography body2` summary text + `Budget: €X` outlined chip + `Allocated: €Y` default chip |
| Budget set, fully allocated | Summary text ends with "(fully allocated)" + chips as above |
| Budget set, over allocated | Summary text ends with "€Z over budget" + `Allocated` chip uses `color="warning"` |
| Unsaved changes | Orange dot (`8px`, `bgcolor: "warning.main"`, `borderRadius: "50%"`) appears left of summary text |
| No participants | `assignedPerPerson` renders as `€0/person`; `unassigned` renders full budget amount |
